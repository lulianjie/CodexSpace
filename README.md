# 固定资产标签打印工具

这是一个免安装的静态网页工具，用于生成并打印固定格式的资产标签，适配 **6cm × 4cm** 横版标签纸，并在右下角显示约 **1cm × 1cm** 的二维码。

## 功能说明

- 固定字段：资产编码、资产名称、规格型号、开始时间、使用部门、存放地点、保管人。
- 必填字段：资产编码、资产名称。
- 二维码内容：资产编码。
- 打印方式：点击“打印标签”后调用浏览器的 `window.print()`，在 **Windows** 系统打印窗口里自行选择打印机，例如 **Gprinter GP-1224T**。
- 标签尺寸：`6cm × 4cm`，并在打印样式中限制页面尺寸与边距。

## 使用方法

1. 直接双击打开 `index.html`，或者放到内网 Web 服务器中访问。
2. 输入资产信息，确认右侧预览效果。
3. 点击“打印标签”，在 Windows 打印对话框中选择目标打印机。
4. 在打印机驱动中将纸张设置为 `60mm × 40mm`。

## 注意事项

- 当前二维码图片通过在线接口 `api.qrserver.com` 生成，因此打印电脑需要能够访问该接口。
- 如果后续需要完全离线版，可再接入本地二维码库或改造成桌面程序。
