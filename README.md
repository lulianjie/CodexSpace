# 固定资产标签打印工具（离线 Windows 7 桌面版）

这是一个**完全离线**的固定资产标签打印程序，使用 Python 标准库 `tkinter` 开发，可打包成 **Windows 7** 桌面程序使用。

## 已满足的需求

- 固定标签尺寸：**6cm × 4cm**，横版。
- 固定字段：资产编码、资产名称、规格型号、开始时间、使用部门、存放地点、保管人。
- 必填字段：**资产编码、资产名称**。
- 右下角二维码：约 **1cm × 1cm**，内容为**资产编码**。
- **完全离线**：二维码本地生成，不依赖任何在线接口。
- **桌面版**：可直接运行 `app.py`，也可以打包成 Windows 可执行程序。
- **Excel 模板下载**：支持导出 Excel 2003 XML `.xls` 模板，也兼容导出 `.csv` 模板。
- **Excel 批量导入**：支持导入模板后批量生成标签，并一次性打印全部导入记录。
- **打印方式**：点击“打印当前”或“打印导入批量”后，程序会生成本地临时打印页并拉起浏览器打印对话框；这样在 **Windows 7** 中你可以自行选择 **Gprinter GP-1224T** 或其他打印机。

## 字体与字号

为了适配低分辨率打印机，程序统一使用：

- 字体：**黑体**（代码中为 `SimHei`）
- 标题字号：`TITLE_FONT_SIZE = 11pt`
- 桌面预览字号：`KEY_FONT_SIZE = 9`、`VALUE_FONT_SIZE = 9`
- 打印字号：`HTML_FONT_SIZE_PT = 9pt`
- 标签文字默认关闭换行逻辑，所有字段按单行显示

如果你实际打印后觉得字太大或太小，可以直接修改 `app.py` 顶部这几个常量：

```python
FONT_FAMILY = "SimHei"
TITLE_FONT_SIZE = 11
KEY_FONT_SIZE = 9
VALUE_FONT_SIZE = 9
HTML_FONT_SIZE_PT = 9
```

## 文件说明

- `app.py`：主程序，桌面界面、预览、Excel 导入导出、批量打印流程都在这里。
- `qrcodegen.py`：本地二维码生成模块，无第三方依赖。
- `build_windows.bat`：Windows 下的一键打包脚本。

## 本地运行

```bash
python app.py
```

> 运行环境建议：Windows 7 上安装可用的 Python 环境后直接运行。

## 打包为 Windows 桌面程序

在 Windows 命令行中执行：

```bat
build_windows.bat
```

如果本机还没有安装 PyInstaller，请先安装：

```bat
python -m pip install pyinstaller
```

打包完成后，生成文件默认位于：

```text
dist\AssetLabelPrinter.exe
```

## Excel 模板使用方法

1. 点击“下载Excel模板”。
2. 打开导出的 `.xls` 模板，用 Excel 填写多条资产数据。
3. 第一行表头不要修改。
4. 每一行代表一张标签。
5. 填写完成后保存，再回到程序点击“导入Excel批量”。
6. 导入完成后可用“上一条 / 下一条”预览，也可以直接点击“打印导入批量”。

## 使用流程

1. 打开程序，填写资产信息。
2. 右侧会实时显示标签预览。
3. 单条打印点击“打印当前”，标签顶部会居中显示“固定资产”。
4. 批量打印先下载模板并填写，再导入 Excel。
5. 点击“打印导入批量”一次生成全部标签。
6. 在弹出的打印窗口里选择你的 **Gprinter GP-1224T** 或其他打印机。
7. 在打印机驱动中把纸张设置成 **60mm × 40mm**。

## 兼容性说明

- 主程序本身不依赖网络。
- 二维码为本地算法生成。
- Excel 模板采用 Excel 2003 XML `.xls` 格式，兼容性较好，且不需要第三方 Python 库。
- 打印步骤使用本机浏览器弹出打印对话框，是为了保留“由你自行选择打印机”的操作方式。
- 如果后续你希望继续升级为“直接在桌面程序里弹出 Windows 打印机选择框并直连打印机驱动”的版本，也可以在这个基础上继续扩展。
