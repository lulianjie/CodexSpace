# 固定资产标签打印工具（离线 Windows 7 桌面版）

这是一个**完全离线**的固定资产标签打印程序，使用 Python 标准库 `tkinter` 开发，可打包成 **Windows 7** 桌面程序使用。

## 已满足的需求

- 固定标签尺寸：**6cm × 4cm**，横版。
- 固定字段：资产编码、资产名称、规格型号、开始时间、使用部门、存放地点、保管人。
- 必填字段：**资产编码、资产名称**。
- 右下角二维码：约 **1cm × 1cm**，内容为**资产编码**。
- **完全离线**：二维码本地生成，不依赖任何在线接口。
- **桌面版**：可直接运行 `app.py`，也可以打包成 Windows 可执行程序。
- **打印方式**：点击“打印标签”后，程序会生成本地临时打印页并拉起浏览器打印对话框；这样在 **Windows 7** 中你可以自行选择 **Gprinter GP-1224T** 或其他打印机。

## 文件说明

- `app.py`：主程序，桌面界面、预览、打印流程都在这里。
- `qrcodegen.py`：本地二维码生成模块，无第三方依赖。
- `build_windows.bat`：Windows 下的一键打包脚本。

## 本地运行

```bash
python app.py
```

> 运行环境建议：Windows 7 上安装可用的 Python 环境后直接运行。

## 打包为 Windows 桌面程序

在 Windows 命令行中执行：

```bat
build_windows.bat
```

如果本机还没有安装 PyInstaller，请先安装：

```bat
python -m pip install pyinstaller
```

打包完成后，生成文件默认位于：

```text
dist\AssetLabelPrinter.exe
```

## 使用流程

1. 打开程序，填写资产信息。
2. 右侧会实时显示标签预览。
3. 点击“打印标签”。
4. 程序会生成本地离线打印页，并自动打开系统默认浏览器。
5. 在弹出的打印窗口里选择你的 **Gprinter GP-1224T** 或其他打印机。
6. 在打印机驱动中把纸张设置成 **60mm × 40mm**。

## 兼容性说明

- 主程序本身不依赖网络。
- 二维码为本地算法生成。
- 打印步骤使用本机浏览器弹出打印对话框，是为了保留“由你自行选择打印机”的操作方式。
- 如果后续你希望继续升级为“直接在桌面程序里弹出 Windows 打印机选择框并直连打印机驱动”的版本，也可以在这个基础上继续扩展。
